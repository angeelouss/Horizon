### [Tampered Claude Code extension with SSH backdoor briefly live on Cursor marketplace](https://phorion.io/blog/offical-claude-code-vsx-compromise/) ⭐️ 7.5/10

A tampered copy of the Claude Code VS Code extension was published on the Cursor marketplace and was live from about 2:27 a.m. to 1:35 p.m. PT on a Thursday, according to Reuters as quoted in the discussion. Cursor&\#x27;s advisory, as quoted in the discussion, says the malicious extension appends an attacker&\#x27;s public key labeled svc-telemetry to the victim&\#x27;s ~/.ssh/authorized\_keys, which would give the attacker SSH access. Anthropic says it did not build or publish the tampered version, that its systems and employee laptops were not compromised, and that its official channels are unaffected. The primary Phorion report was not available in the supplied material, so these details rest on the Cursor advisory and press coverage.

hackernews · \_chall · Oct 30, 07:09 · [Discussion](https://news.ycombinator.com/item?id=50300683)

**「How the tampered package worked」** The malicious build was published under the official identifier anthropic.claude-code at version 2.1.313, so its name matched the legitimate extension. It was designed to activate after VS Code started or when its webview opened, and it attempted to add an attacker-controlled key labeled &quot;svc-telemetry&quot; to the user&\#x27;s SSH authorized\_keys file. Cursor&\#x27;s advisory also says the payload tried to enable the local SSH service and open a reverse SSH tunnel.

**「Who should check」** Developers who installed the Claude Code extension from the Cursor marketplace during that window should check their ~/.ssh/authorized\_keys file for an entry labeled svc-telemetry, using the check Cursor describes. Affected users should also treat any unexpected key as a possible compromise and review access to their machines.

**「Open questions in the thread」** Commenters disagreed about who is responsible: one asked whether the extension came from Anthropic, and an Anthropic employee replied that the tampered copy was published by a malicious actor using access to Cursor&\#x27;s marketplace. One commenter noted that the coverage they had read mentions Open VSX and the Cursor marketplace but not the official Microsoft registry, and said they were no longer sure the official build was clean.

### [ChatGPT HTML Previews Sandbox Escape Exposed Accounts via Share Links](https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/) ⭐️ 7.0/10

Parameter Labs disclosed a chained exploit against ChatGPT&\#x27;s HTML previews, the sandboxed iframe feature formerly called Canvas, and OpenAI has since closed the hole. According to the researchers&\#x27; account, a crafted ChatGPT share URL that another signed-in user visited could exfiltrate that user&\#x27;s private data or take actions on their behalf. OpenAI reportedly paid a $5,000 bug bounty; the item does not show evidence that the flaw was exploited in the wild.

rss · Simon Willison · Oct 31, 23:15
